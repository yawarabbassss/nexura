## 🌟 Overview

**Nexura Enterprises** is a modern, high-speed digital growth web platform engineered for startups, B2B services, professional firms, field service contractors, ecommerce brands, and growing enterprises across the globe, especially in the United States.

### Key Capabilities & Features
- 🚀 **Sub-Second Core Web Vitals Performance**: Built on React 18 & Vite with Tailwind CSS.
- 🎯 **16 Specialized Industry Vertical Roadmaps**: Dentists, Med Spas, Cosmetic Clinics, Law Firms, HVAC, Plumbing, Roofing, Remodeling, Real Estate, Auto Detailing, Home Cleaning, Landscaping, Restoration, Restaurants, and Ecommerce.
- 🔄 **Two-Way Infinite Marquee Industry Showcase**: Smooth GPU-accelerated two-direction industry marquee rows with pause-on-hover interaction.
- 🤖 **24/7 Conversational AI Lead Assistant**: Rule-based decision tree chatbot with instant lead intake and pre-qualification.
- 📬 **Instant Silent Lead Capture**: Automatic background lead routing & notification system.
- 📊 **Interactive Growth Tools**: Free $500 AI Audit tool, Ad Creative Generator, Sitemap Analyzer, YouTube Thumbnail Generator, and Blog Banner Tool.
- 📚 **Growth Insights & Blog System**: Fluff-free, actionable articles on Local SEO, AI Chatbots, Web Speed, and Business Automation.

## ⚙️ Quick Start Guide

### Prerequisites
- Node.js `v18.0.0` or higher
- npm `v9.0.0` or higher

### Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/nexura-enterprises.git
   cd nexura-enterprises
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
   The optimized production bundle will be generated in the `dist/` directory.
